# Independent Peer Reviews & Audits

This folder collects the independent reviews, audit reports, and reviewer validation scripts produced during the study's review cycles.

## Contents

- **`first.md`**: Initial independent adversarial review of the first rescue study (round 1).
- **`INDEPENDENT_REVIEW_V3.md`**: Detailed adversarial review evaluating the revised methodology and empirical claims (round 3).
- **`final_audit/`**: Final verification audit report (`audit.md`) and supporting verification scripts.
- **`v3_checks/`**: Read-only verification scripts (c1–c8) written to probe specific claims independently without altering existing data.
